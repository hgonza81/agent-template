# Agent instructions

- Treat [`specs/agent-template/tasks.md`](specs/agent-template/tasks.md) as the ordered implementation checklist.
- For each completed task item in that file, create one descriptive git commit before moving to the next task.
- Keep each commit scoped to its task, include relevant validation, and avoid mixing unrelated work.
- Do not mark a task complete until its acceptance checks pass and its task-specific commit is recorded.
